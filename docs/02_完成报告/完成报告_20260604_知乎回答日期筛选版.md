# 完成报告：知乎回答日期筛选版（2026-06-04）

## 本次上传版本

- 来源目录：`C:\参赛文档\知识图鉴_知乎回答日期筛选版_20260604`
- 插件名称：知识图鉴
- Manifest 版本：`2.0.0`
- 发布定位：在侧边栏中加入知乎回答批量导出，并支持按回答创建日期筛选导出范围。

## 更新内容

1. 新增侧边栏「导出回答」页签，入口位于原有分析/资产/复盘等页签旁。
2. 新增起始日期和结束日期输入框，默认起始日期为 `2026-05-17`，结束日期留空表示导出到当前时间。
3. 新增日期校验：日期必须为 `YYYY-MM-DD`，且起始日期不能晚于结束日期。
4. 新增知乎回答导出脚本 `export_zhihu_answers.js`，通过已登录的知乎页面读取当前账号回答列表。
5. 导出时按回答 `created_time` 做区间过滤；两个日期都留空时导出全部回答。
6. 导出文件名随日期范围自动生成，例如 `zhihu_answers_2026-05-17_to_2026-06-04.json`。
7. 导出结果包含回答标题、问题链接、回答链接、创建/更新时间、赞同数、评论数、内容文本等字段。
8. 同步更新品牌文案为「知识图鉴：把每一次创作编译成下一次的资产」。

## 使用说明

1. 在同一个浏览器中先登录 `https://www.zhihu.com/`。
2. 打开插件侧边栏，进入「导出回答」。
3. 选择起始日期和结束日期，点击「批量导出我的回答」。
4. 导出的 JSON 文件保存位置由浏览器下载设置决定，通常是系统「下载」文件夹。

## 注意事项

- 该版本是 `2026-06-04` 的日期筛选发布包；如果后续要合并到主线，需要再核对主线已有的知乎开放平台和文档改动，避免覆盖。
- 插件没有在代码中强制写死导出目录，其他用户新装后会按自己的 Chrome / Edge 下载设置保存。
