# 知识图鉴

知识图鉴是一个面向持续创作者的 Chrome 扩展，用来把知乎创作内容整理成可搜索、可复盘、可继续创作的个人知识资产。

这个版本包含知乎回答批量导出能力，并支持按回答创建日期筛选导出范围。

## 功能

- 抓取知乎文章或手动粘贴内容。
- 用 AI 分析文章定位、写作技法、可复用素材、立意精华和知识节点。
- 管理素材、立意和作品资产。
- 用时间轴查看作品演化。
- 在侧边栏批量导出自己的知乎回答。
- 导出回答时可选择起始日期和结束日期。

## 安装

1. 在 GitHub 页面点击 `Code`。
2. 点击 `Download ZIP` 下载代码。
3. 解压 ZIP。
4. 打开 Chrome / Edge 的扩展程序页面。
5. 开启「开发者模式」。
6. 点击「加载已解压的扩展程序」。
7. 选择解压后的文件夹。

## 导出知乎回答

1. 在同一个浏览器中登录 `https://www.zhihu.com/`。
2. 打开插件侧边栏。
3. 进入「导出回答」。
4. 选择起始日期和结束日期。
5. 点击「批量导出我的回答」。

结束日期留空表示导出到当前时间。起始日期和结束日期都留空时，会导出全部回答。

导出的 JSON 文件保存位置由浏览器下载设置决定，通常是系统「下载」文件夹。

## 导出文件名

不筛选日期时：

```text
zhihu_answers.json
```

按日期筛选时：

```text
zhihu_answers_2026-05-17_to_2026-06-04.json
```
