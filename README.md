# 知识图鉴 2.0

知识图鉴 2.0 是一个面向持续创作者的 Chrome 扩展，用来把自己的知乎文章、手动粘贴内容和速记沉淀为可搜索、可追问、可复盘的个人作品图鉴。

## 核心能力

- 一键抓取知乎内容或手动粘贴文章。
- AI 分析文章定位、创作者优势、写作技法、可复用素材、立意精华、知识节点和下一步选题。
- 追问 AI：6 个单篇追问模板，自定义追问，并可沉淀到素材库或立意库。
- 资产库：按素材、立意、作品浏览。
- 3D 知识地图：用球面节点展示作品中的知识节点关系。
- 时间轴牌组：按日期浏览作品演化。
- 复盘 Tab：查看本周作品、本周字数、日均频率、月度对比、创作方向分析，并可打开 AI 周复盘对话。
- 本地 Markdown 文件夹同步与 Obsidian Vault 兼容导出保留在设置页高级能力中。

## 本地运行

1. 打开 Chrome 扩展管理页。
2. 开启「开发者模式」。
3. 选择「加载已解压的扩展程序」。
4. 选择本项目文件夹 `zhijing_v4`。
5. 在扩展选项页配置 API Key。
